# راه‌اندازی تلگرام (بات + کانال)

## مراحل

1. در تلگرام با **@BotFather** بات بسازید → `Bot Token` را کپی کنید.
2. یک **کانال** بسازید (یا از کانال موجود استفاده کنید).
3. بات را به کانال اضافه کنید و **ادمین** کنید (حق ارسال پیام).
4. شناسه کانال:
   - اگر کانال **عمومی** است: `@YourChannelUsername` (با @)
   - اگر **خصوصی** است: عدد مثل `-1001234567890` (با ربات @getidsbot یا از لاگ `getUpdates` بعد از یک پیام در کانال)

## پنل Barbin

**تنظیمات → پیام‌رسان‌ها → ایجاد**

| فیلد | مقدار |
|------|--------|
| درایور | تلگرام |
| Bot Token | از BotFather |
| شناسه کانال | `@channel` یا `-100…` |

دکمه **تست** را بزنید — باید پیام «تست اتصال Barbin» در کانال بیاید.

## ارسال لیست فروش

بعد از تولید PDF روی فایل فروش: **ارسال به کانال** → پیام‌رسان تلگرام را انتخاب کنید.

## محیط (اختیاری)

```env
# فقط اگر پروکسی/میزبانی جایگزین API دارید
TELEGRAM_API_BASE=https://api.telegram.org
```

## Runflare

خروجی HTTPS به `api.telegram.org` باید باز باشد. در صورت فیلتر از تونل یا `TELEGRAM_API_BASE` سازگار استفاده کنید.
