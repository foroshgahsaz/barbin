# ماژول انبار (Barbin / stock)

این پوشه مستندات و نمونه‌های ماژول انبار را نگه می‌دارد. **کد Laravel در ساختار استاندارد `app/` قرار دارد.**

تاریخ‌ها در پنل، PDF و نمودارها **شمسی (جلالی)** با اعداد فارسی نمایش داده می‌شوند. تایم‌زون پیش‌فرض: `Asia/Tehran` (`APP_TIMEZONE`).

## ساختار

- `samples/` — فایل‌های نمونه Excel/CSV (بدون داده حساس)
- `documentation/` — راهنمای ستون‌ها و فرآیند
- `exports/` — خروجی‌های محلی (در Git نیست)
- `reports/` — گزارش‌های محلی (در Git نیست)

## فرمت پیش‌فرض فایل موجودی

| ستون | نام‌های قابل قبول |
|------|-------------------|
| کد کالا | کد کالا، کد، product_code |
| شرح | شرح کالا، شرح، description |
| واحد | واحد، unit |
| موجودی | موجودی، **مانده**، quantity، qty |
| قیمت خرید (اختیاری) | قیمت خرید، purchase_price، cost |

**کد کالا همیشه رشته (String) است** — صفرهای ابتدایی حفظ می‌شوند.

## فرمت فایل فروش مدیر

| ستون | نام‌های قابل قبول |
|------|-------------------|
| کد کالا | کد کالا، کد |
| شرح | شرح کالا |
| واحد | واحد کالا، واحد |
| مبلغ | مبلغ، قیمت، price |

پس از پردازش، ستون «موجودی» به خروجی اضافه می‌شود و از پنل می‌توان Excel نهایی را دانلود کرد.

## Snapshot

هر تأیید موجودی یک `inventory_snapshots` + ردیف‌های `inventory_snapshot_items` ایجاد می‌کند؛ Snapshotهای قبلی حذف نمی‌شوند.

## تنظیمات لازم برای SMS و پیام‌رسان

- پنل Filament → تنظیمات SMS.ir (API Key، Template ID، پارامترهای JSON مطابق پنل SMS.ir)
- جدول `messengers` برای **تلگرام**، بله، روبیکا — راهنمای تلگرام: [`documentation/telegram-setup.md`](documentation/telegram-setup.md)

فایل‌های واقعی آپلود و PDF در `storage/app/private` نگهداری می‌شوند.
